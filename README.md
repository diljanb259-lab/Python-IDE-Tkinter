Python IDE - Tkinter

A simple Python IDE built with Python and Tkinter. It allows users to write, open, edit, save, and run Python programs through a graphical interface.

Features
Create a new Python file
Open existing .py and .txt files
Save and Save As
Run Python programs
Stop running programs
Integrated output console
Clear output
Line numbers
Keyboard shortcuts
Error output display
Resizable editor and output areas
Technologies
Python
Tkinter
Subprocess
Threading
Requirements
Python 3.x
Tkinter

Tkinter is normally included with standard Python installations on Windows.

How to Run

Clone the repository:

git clone https://github.com/diljanb259-lab/Python-IDE-Tkinter.git

Open the project folder:

cd Python-IDE-Tkinter

Run the program:

python python_ide_clean.py
Keyboard Shortcuts
Shortcut	Action
Ctrl + N	New File
Ctrl + O	Open File
Ctrl + S	Save File
F5	Run Code
